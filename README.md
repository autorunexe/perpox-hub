# PerPox Overlay

Overlay cam transparan mengikuti contoh di folder `src`:

- Logo PerPox berputar 3D dengan efek glow dan glitch warna `#ffa800`.
- Box hitam memakai `#0f0f0f`.
- Teks utama berganti: `DONATE SAWERIA ON BIO` dan `MEDIA SHARE ON BIO` bergantian.
- Baris bawah menampilkan ikon YouTube dan TikTok dengan `: PERPOX`.

## Pakai di OBS

1. Tambahkan **Browser Source** pada scene.
2. Pilih **Local file** dan buka `index.html`.
3. Atur ukuran source ke **1920 × 1080**.

Canvas di luar overlay transparan. Teks utama berganti otomatis tiap 4,6 detik. File HTML memakai aset di folder `src`, jadi biarkan folder tersebut tetap bersama `index.html`.
